# Apple Financial Intelligence Dashboard

Interactive financial dashboard prepared for the Handshake data-analysis project.

## GitHub Pages
This repository is structured so that `index.html` is the public dashboard entry point.

1. Upload the contents of this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files and the `/ (root)` folder.
5. Save and wait for GitHub Pages to deploy.
6. Open the generated Pages URL in a private/incognito window and test the dashboard.

## Included
- `index.html` — interactive web dashboard
- `Apple_Financial_Intelligence.xlsx` — supporting Excel analysis workbook
- `README.md` — deployment notes

## Source
Apple Inc. FY2025 Form 10-K, U.S. Securities and Exchange Commission (SEC).
The dashboard identifies the source and provides links to the filing and Apple Investor Relations SEC filings page.

## Important
Keep the folder structure intact when uploading. If additional asset files are present, upload them with `index.html` rather than uploading only the HTML file.
